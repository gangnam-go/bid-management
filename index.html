📌 이 시스템의 목적

나라장터 적격심사 입찰에서 최적의 투찰금액을 계산하고, 과거 낙찰 데이터를 분석하여 발주처별 경향을 파악하는 시스템입니다.

🔢 핵심 용어
용어의미출처
기초금액발주처가 산정한 공사 기준금액입찰 공고문
A값복수예비가격 추첨 후 산술평균값 (정산비용)입찰 공고문
순공사원가실제 공사에 드는 최소 원가입찰 공고문
낙찰하한율기초금액 대비 낙찰 가능한 최저 비율입찰 공고문
사정률낙찰하한율 구간 내 투찰 위치를 결정하는 비율시스템 계산
🧮 추천 투찰금액 계산식
투찰금액 = ( 기초금액 − A값 ) × ( 낙찰하한율 ÷ 100 ) × ( 사정률 ÷ 100 ) + A값
⚠️ 배제기준: 계산된 투찰금액이 순공사원가 × 98% 보다 낮으면 자동으로 올라갑니다. 공고문에 해당 조항이 있는 경우에만 적용하세요.
📊 역산 사정률
역산 사정률 = ( ( 실제낙찰금액 − A값 ) ÷ ( 기초금액 − A값 ) ) ÷ ( 낙찰하한율 ÷ 100 ) × 100

실제 기초금액(예정가격)이 있으면 더 정확한 역산 사정률을 계산합니다. 순공사원가 98%미만 탈락 건은 사정률이 왜곡되므로 평균 계산에서 제외됩니다.

1
입찰 공고 확인 — 기초금액, A값, 순공사원가, 낙찰하한율, 예비가격범위(±2%/±3%) 확인
2
정보 입력 — 발주처 입력 시 과거 데이터 기반 추천 사정률 자동 계산
3
수익성 확인 — 순공사원가/기초금액 비율로 안정권/주의/위험 판단 (92% 초과 시 입찰 재고)
4
투찰 후 ◆ 버튼 — 투찰 완료 상태로 변경
5
개찰 후 사후 복기 — 실제 예정가격/순공사원가/낙찰가 입력하여 역산 사정률 정확도 향상

낙찰하한율적용 기준
89.745% ~ 85.745%공고문에 명시된 값 사용 (기본 87.745%)

예비가격범위 ±2%는 변동폭이 작아 역산 사정률 신뢰도가 높고, ±3%는 변동폭이 커 표준편차가 크게 나올 수 있습니다. 같은 발주처라도 범위별로 구분하여 분석합니다.
