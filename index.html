📌 이 시스템의 목적

나라장터 적격심사 입찰에서 최적의 투찰금액을 계산하고, 과거 낙찰 데이터를 분석하여 발주처별 경향을 파악하는 시스템입니다.

입찰 공고문에서 기초금액, A값, 순공사원가, 낙찰하한율 등을 입력하면 추천 투찰금액이 자동으로 계산됩니다.

🧮 추천 투찰금액 계산식

투찰금액은 아래 공식으로 계산됩니다.

▶ 기본 계산식
투찰금액 = ( 기초금액 − A값 ) × ( 낙찰하한율 ÷ 100 ) × ( 사정률 ÷ 100 ) + A값
▶ 예시 (기초금액 2,000,000,000 / A값 100,000,000 / 낙찰하한율 87.745% / 사정률 100%)
투찰금액 = ( 2,000,000,000 − 100,000,000 ) × 0.87745 × 1.00 + 100,000,000
         = 1,900,000,000 × 0.87745 + 100,000,000
         = 1,767,155,000
⚠️ 배제기준 적용: 계산된 투찰금액이 순공사원가 × 98% 보다 낮으면 자동으로 배제기준값으로 올라갑니다.
배제기준보다 낮게 투찰하면 입찰에서 자동 배제되므로 반드시 확인이 필요합니다.
📊 역산 사정률 계산식

과거 낙찰된 공사의 실제 낙찰가를 역으로 분석하여 "그때 사정률이 얼마였으면 이 금액이 나왔을까"를 계산합니다.

이 값들의 평균이 해당 발주처의 추천 사정률로 활용됩니다.

▶ 역산 사정률 계산식
역산 사정률 = ( ( 실제낙찰금액 − A값 ) ÷ ( 기초금액 − A값 ) ) ÷ ( 낙찰하한율 ÷ 100 ) × 100
🔄 업무 프로세스
1
입찰 공고 확인 — 나라장터에서 공고문을 열어 기초금액, A값, 순공사원가, 낙찰하한율을 확인합니다.
2
정보 입력 — 발주처명, 공사명, 공고번호, 1·2차 일시, 각 금액을 입력합니다. 발주처가 과거 데이터가 있으면 추천 사정률이 자동으로 채워집니다.
3
투찰금액 확인 — 추천 투찰금액을 확인하고 배제기준 경고가 있는지 체크합니다. 사정률을 조정하여 금액을 변경할 수 있습니다.
4
저장 및 투찰 — 저장 후 나라장터에서 실제 투찰합니다. 투찰 후 ◆ 투찰 버튼을 눌러 상태를 변경합니다.
5
개찰 결과 입력 — 개찰 후 실제 낙찰가를 입력하고 저장합니다. 이 데이터가 다음 입찰의 추천 사정률 계산에 활용됩니다.
